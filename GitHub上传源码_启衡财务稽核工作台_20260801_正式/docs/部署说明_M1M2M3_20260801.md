# 启衡财务稽核工作台（M1–M3）部署说明

## 交付内容

- `启衡财务稽核工作台_M1M2M3_交付版_20260801.exe`：Windows 桌面工作台；
- `启衡财务稽核工作台_演示原型.html`：使用虚拟数据的演示原型；
- `操作手册_M1M2M3_20260801.md`：财务人员操作和异常处理；
- `整改历程_交付架构与验证清单_20260801.md`：规则、验证和已知边界；
- `submission.json`、评测报告、ROI、现状诊断、AI 协作复盘：比赛验收材料；
- `源码/`：可构建源码及本文件。

## 运行条件

- Windows 10/11 x64；
- 导师提供的启衡 ERP/API 已启动；
- 网络可访问 ERP API，例如本机 `http://127.0.0.1:8081`；
- 由 ERP 开发者中心创建的 API Key。Key 不随 EXE 分发。

## 启动 ERP（本地 Docker 示例）

在包含镜像文件的目录执行：

```powershell
docker load -i qiheng-env-1.0-amd64.tar.gz
docker run --name qiheng -d -p 8080:8080 -p 8081:8081 qiheng-env:1.0-amd64
```

确认 API 已启动：

```powershell
Invoke-WebRequest http://127.0.0.1:8081/v1/health
```

出现 401 代表 API 已响应但尚未提供 Key，是正常现象。ERP 门户通常是 `http://127.0.0.1:8080`，工作台应连接 API 端口 `8081`。

## 首次使用

1. 在 ERP 开发者中心创建 Key，按业务实际申请 `expense:read`、`approval:read`、`attachment:read`、`invoice:read`、`master-data:read`；需要回写时再申请 `expense:review`。
2. 启动 EXE，填写 API 地址和 Key。
3. 登录后点击“刷新待审单据”。M2 当前队列、单据附件、审批记录和台账均从当前 API 读取；本机旧缓存不会作为实时结果。
4. 完成 M2 人工确认、预检与安全写回，或运行 M3 全量只读稽核。

## 数据与安全

- EXE 不含 API Key、ERP 单据缓存或预写回结果；新电脑启动后会停在登录页。
- 原始票据仅为本地 OCR、人工复核与审计包暂存；系统未调用外部云模型。
- M2 写回仅新增审核意见，不改变单据状态、不支付、不删除；ERP 存在任何既有审核意见时，客户端跳过写回。
- M3 只形成本地稽核任务，不写回 ERP。

## 常见故障

见《操作手册_M1M2M3_20260801.md》。如 Docker 未启动、Key 被吊销、缺少权限或附件不可读，工作台会显示具体错误和下一步处理方式。
