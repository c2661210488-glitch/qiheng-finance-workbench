# 启衡财务稽核工作台（M1–M3）

面向财务复核人员的 Windows 财务稽核工作台。应用登录后连接 ERP API **实时只读拉取**数据，完成费用报销审核（M2）与全量发票台账稽核（M3）；人工确认后才允许写回审核意见。

## 本仓库内容

本次通过网页上传时保留了完整的交付目录层级，源码、测试、文档与演示原型均在：

[`GitHub上传源码_启衡财务稽核工作台_20260801_正式/`](./GitHub上传源码_启衡财务稽核工作台_20260801_正式/)

其中包括：

- `app.py`：桌面工作台入口；
- `src/`：M2 规则、OCR 与 M3 台账扫描逻辑；
- `tests/`：规则、回写安全与扫描测试；
- `tools/`：全量审核、回写与交付构建工具；
- `docs/`：部署、操作、ROI、评测与整改说明；
- `demo/`：虚拟数据演示 HTML。

## 已验证范围

- M2：300 单实时批量审核完成，公开 30 单回归判责 30/30；
- M3：23,461 条全量发票台账扫描，输出可追溯风险清单；
- 写回安全：仅人工确认意见可写回；已有不同 ERP 意见不覆盖；
- 自动化测试：37/37 通过；
- 交付 EXE、`submission.json` 与校验记录在课程提交包中一并提供。

## 运行与安全

请按源码目录内的部署说明安装 Python 依赖并启动。API 地址与 Key 由使用者在桌面端登录页输入，不写入源码、仓库或提交包。系统不自动改变 ERP 单据状态、付款数据或全局规则。

> 本项目用于课程交付与演示；演示 HTML 使用明确标识的虚拟数据。
