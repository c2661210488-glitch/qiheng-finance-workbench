# 启衡财务稽核工作台｜FDE 共学营结课作业

面向财务复核人员的 Windows 财务稽核工作台。应用连接 ERP API 后实时拉取数据，完成费用报销审核（M2）与全量发票台账稽核（M3）；AI/OCR 只给可解释建议，最终决定由财务人员作出。

## 已验证结果

- 公开集：审核结论 30/30，违规代码 30/30；
- M2：300/300 形成结果；300/300 审核意见写回，118 建议通过、147 建议驳回、35 转人工复核；
- 写回后 300 单均保持 `PENDING`，未自动审批、付款或删除；
- M3：本次快照扫描 23,461 条发票台账，形成 40 组重复票和 110 条其他异常；
- 自动化回归：29/29；
- 官方 `submission.json` 格式校验：无 error。

## 写回边界

首次人工确认可写回审核建议。财务发现错判后，可以再次写回人工最终意见；ERP 历史意见不删除，新增的最新人工意见作为当前建议。写回只新增审核意见，不改变单据状态、付款状态或其他业务数据。

## 运行与安全

API 地址与 Key 由使用者在桌面端登录页输入，不写入源码、仓库或提交包。RapidOCR 在本地运行，原票不发送到外部模型。演示 HTML 使用明确标识的虚拟数据。

> 系统写回的是审核建议，不是自动审批；最终放行仍由财务人员在 ERP 中操作。
